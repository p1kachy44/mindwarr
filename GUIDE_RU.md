# Руководство по установке и использованию "Воин мотивации"

Этот документ содержит подробные инструкции по установке и запуску Telegram бота "Воин мотивации" на вашем локальном компьютере.

## 1. Подготовка окружения

### Установка Python (если не установлен)
1. Скачайте Python 3.7 или выше с [официального сайта](https://www.python.org/downloads/)
2. При установке на Windows отметьте галочку "Add Python to PATH"
3. Проверьте установку, выполнив в командной строке:
   ```
   python --version
   ```

### Создание бота в Telegram
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям, чтобы задать имя бота
4. После создания бота BotFather отправит вам токен (выглядит примерно как `123456789:ABCDefGhIJKlmNoPQRsTUVwxyZ`)
5. **Сохраните этот токен в надежном месте**

## 2. Установка проекта

### Клонирование репозитория
```bash
git clone https://github.com/your-username/telegram-motivation-bot.git
cd telegram-motivation-bot
```

### Установка зависимостей
```bash
pip install python-telegram-bot flask
```

## 3. Настройка проекта

### Создание файла конфигурации
Создайте файл `.env` в корневой директории проекта и добавьте в него следующее:
```
TELEGRAM_BOT_TOKEN=ваш_токен_полученный_от_botfather
```

Или, вы можете напрямую отредактировать файл `bot.py` и вставить ваш токен в соответствующую переменную.

## 4. Запуск бота

### Запуск через Python
```bash
python bot.py
```

### Проверка работы бота
1. Найдите своего бота в Telegram по имени, которое вы ему дали
2. Отправьте команду `/start`
3. Бот должен ответить приветственным сообщением и начать отправлять ежедневные сообщения

## 5. Команды бота

- `/start` - Активировать ежедневные сообщения (8:00 утро, 22:00 вечер)
- `/stop` - Приостановить отправку сообщений
- `/help` - Показать справочную информацию

## 6. Запуск веб-демо (опционально)

Если вы хотите посмотреть примеры сообщений бота через веб-интерфейс:

```bash
python simple_web_demo.py
```

Затем откройте `http://localhost:5000` в вашем веб-браузере.

## 7. Размещение бота на сервере

Для круглосуточной работы бота рекомендуется разместить его на VPS или сервисе PaaS:

### Вариант 1: Heroku (платный)
1. Создайте аккаунт на [Heroku](https://www.heroku.com)
2. Установите [Heroku CLI](https://devcenter.heroku.com/articles/heroku-cli)
3. Добавьте в корень проекта файл `Procfile` с содержимым:
   ```
   worker: python bot.py
   ```
4. В корне проекта выполните:
   ```bash
   heroku login
   heroku create your-bot-name
   heroku config:set TELEGRAM_BOT_TOKEN=ваш_токен
   git push heroku main
   heroku ps:scale worker=1
   ```

### Вариант 2: Python Anywhere (есть бесплатный план)
1. Зарегистрируйтесь на [PythonAnywhere](https://www.pythonanywhere.com/)
2. Загрузите файлы проекта
3. Настройте переменные окружения с вашим токеном
4. Создайте и запустите задачу через "Tasks" для запуска бота

## 8. Настройка сообщений

Для изменения содержания сообщений отредактируйте файл `motivational_content.py`:
- `MORNING_MOTIVATIONS` - массив утренних мотивационных сообщений
- `EVENING_REFLECTIONS` - массив вечерних рефлексивных вопросов

## 9. Устранение неполадок

### Бот не отвечает
1. Проверьте правильность токена
2. Убедитесь, что бот запущен и работает
3. Проверьте логи на наличие ошибок

### Ошибки при установке зависимостей
Попробуйте установить зависимости с явным указанием версии:
```bash
pip install python-telegram-bot==20.4 flask==2.3.2
```
